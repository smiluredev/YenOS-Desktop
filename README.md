## ⚡ VaporOS

> *The official successor to ¥enOS — an independent Arch-based Linux distribution designed to offer an immersive, modern, and optimized visual experience.*

---

### 🚀 About the Project

**VaporOS** evolved from the former ¥enOS (which ran via a Slax-based LiveUSB) into a complete, independent operating system capable of native installation on a hard drive. Combining the robustness and flexibility of the Arch Linux base with its own customized visual identity, VaporOS aims to deliver a fluid environment centered around the **KDE Plasma** ecosystem.

### ✨ Key Features

* **Solid Foundation:** Built on Arch Linux, ensuring access to up-to-date packages and high performance.
* **Native Installation:** Ready to be installed directly on hardware (SSD/HD support).
* **Unique Identity:** Custom splash screen, exclusive branding adjustments, and a polished interface.
* **Graphical Environment:** Uses KDE Plasma for an experience rich in customization and productivity.

### 🗺️ Roadmap & Next Steps

The VaporOS ecosystem is constantly expanding. Upcoming versions will bring major structural advancements:

* **Mobile Version:** Focus on bringing a native Linux experience to smartphones using the Droidian ecosystem.
* **ARM / TV Box Version:** Integration with **KDE Plasma Big Screen**, allowing you to transform TV boxes and larger screens into smart multimedia hubs optimized for remote control.
